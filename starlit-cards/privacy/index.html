二、处理的信息和目的

根据 V3.2.1 安卓工程的初步检查，游戏接入 TapTap 登录及实名认证、防沉迷服务，Android 应用本身声明网络访问和网络状态权限。下列说明需在发布前结合最终 APK、SDK 版本及真实运行行为复核。

1. TapTap 账号登录

当您选择 TapTap 登录时，TapTap SDK 提供账号授权服务，游戏可能接收用于识别登录用户的 TapTap 账号标识（例如 OpenID）与授权状态，以完成登录及绑定实名认证流程。

2. 实名认证和未成年人防沉迷

游戏接入 TapTap 合规认证能力，依据认证结果决定是否允许进入游戏及按规则限制未成年人的游戏时间。身份认证可能由 TapTap 进行。开发者是否取得姓名、身份证号等原始字段，需要对 SDK 数据接口与真实运行流程复核，不能在未核对前作出绝对承诺。

3. 运行环境与连接信息

TapTap 官方说明，其登录和合规 SDK 在提供相应功能时可能处理设备型号、系统版本、CPU、网络类型、Android ID、设备内存及网络状态等信息，用于兼容性和服务运行。具体由实际启用的 SDK 模块及版本决定。

六、个人信息权利

用户可以依法申请查阅、复制、更正、删除其个人信息、撤回以同意为基础的授权并了解个人信息处理规则。正式运营前，开发者需要开通第一条所述的有效联系渠道并核实具体申请与响应流程。因法律要求必要的实名认证流程，撤回相关授权可能导致无法继续使用联网游戏服务。

七、未成年人保护

本游戏使用 TapTap 合规认证服务落实未成年人实名认证及防沉迷限制。涉及不满十四周岁未成年人的个人信息时，应依法取得必要的监护人同意并履行专门保护义务。具体执行措施和用户反馈渠道在上线前核实完善。

八、政策更新

如信息处理目的、类别、方式或第三方服务发生变化，将在游戏内通过适当方式告知用户，并在依法需要时重新取得授权。正式上线时以公示的生效日期和实际发布版本为准。
